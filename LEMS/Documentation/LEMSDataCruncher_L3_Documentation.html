Standard Mode: File Picking & Graphing (When Pairs File is Absent)

Standard Workflow

When running LEMSDataCruncher_L3.py in a directory that does not contain PairsUnformattedDataL2FilePaths.csv, LEMS operates in Standard Mode. In this mode, LEMS processes and graphs test groups as a standard sequential comparison without pair difference calculations, alternating background shading, or top header boxes.

File Discovery & Selection

At startup, LEMS prompts for the user interface mode: Enter cli for command line interface or default to graphical user interface.

1. Graphical User Interface (GUI Mode — Default)

  • Folder Selection: A directory picker opens, allowing you to select the folder containing your Level 2 test outputs.
  • Automatic File Discovery: select_l2_files_gui() recursively searches the selected directory for all files matching *UnFormattedDataL2.csv.
  • Pre-Selection & Retention: If UnformattedDataL2FilePaths.csv already exists in the folder, previously selected files are pre-checked in the list and their display order is preserved.
  • Interactive Multi-Select Dialog: A Tkinter dialog titled “Select Tests to Compare” displays discovered tests with checkboxes, allowing you to include or exclude specific tests.
  • Manifest Generation: Upon clicking OK, the chosen paths are written to UnformattedDataL2FilePaths.csv in the project folder and loaded into memory as list_input.

2. Command Line Interface (CLI Mode)

  • Folder Prompt: Prompts Enter folder path: .
  • Existing Manifest Detection: Checks if UnformattedDataL2FilePaths.csv exists in the folder. If found, prints all saved test paths and prompts Run all tests listed? (y/n): . Entering n allows you to edit the CSV file in Excel/text editor before proceeding.
  • Directory Crawl: If UnformattedDataL2FilePaths.csv is not found, LEMS automatically crawls subdirectories (up to 3 levels deep) for all UnFormattedDataL2.csv files, writes them to a new UnformattedDataL2FilePaths.csv, and prompts you to verify the list.

Graphing in Standard Mode

In Standard Mode, plotting steps (Steps 3 through 9) use list_input from UnformattedDataL2FilePaths.csv:

  • Plotting Sequence: Strictly follows the order in which tests appear in UnformattedDataL2FilePaths.csv.
  • X-Axis Tick Labels: Defaults to each test group's directory name (e.g. VG2020 Dry Doug Fir, Princess Baseline). In single plots, labels are rotated 90 degrees; in batch plots, labels are angled at 45 degrees.
  • Visual Layout: Rendered on standard white axes with horizontal gridlines. No alternating light-gray shading (#f2f2f2), no vertical group dividers, and no top header boxes are drawn.
  • Hover Tooltips (Scatter Plots): Scatter plots (Steps 7 & 8) retain full interactive cursor hover functionality, showing replicate test points and group averages.
  • Output File Naming: Standard plots are saved directly to the root project folder without the Pairs prefix:
    • Boxplots (Steps 3 & 4): L3BoxPlot_[variable].png
    • Bar Charts (Steps 5 & 6): L3BarChart_[variable].png
    • Scatter Plots (Steps 7 & 8): L3ScatterPlot_[variable].png
    • Subplots (Step 9): L3SubplotScatterPlot.png
  • Tabular Data Output: Step 1 compiles test results into standard FormattedDataL3.csv (rather than PairsFormattedDataL3.csv).

2. PairsUnformattedDataL2FilePaths.csv Specification

Configuration File

In this branch, the presence of PairsUnformattedDataL2FilePaths.csv in the active root folder enables shaded pair plotting in Steps 3 through 9 (as well as multi-pair calculations in Steps 2 & 12). If the file is not present, LEMS operates in Standard Mode.

Required Column Headers

The CSV file requires 4 columns (case-insensitive):

  • Name: Human-readable display label for the test (or title of the pair comparison block in header boxes).
  • test_code: Short code identifying the test condition (e.g. 1B, 1R1, 2B).
  • data_key: Match identifier for data lookup (e.g. 1B) OR pair relationship syntax (e.g. d1B/1R1).
  • path: Absolute path to the test group's UnFormattedDataL2.csv file. Must be left empty on pair definition rows.

Row Types: Data Rows vs. Pair Rows

Row Type Name test_code data_key path Purpose
Data Row Baseline Fire 1B 1B /path/to/Group1/UnFormattedDataL2.csv Loads test data into L3. Placed as a test point on plots. data_key registers test index.
Data Row Improved Stove 1R1 1R1 /path/to/Group2/UnFormattedDataL2.csv Loads comparison test data. Name displays as bottom x-axis tick label.
Pair Row Improved vs Baseline (blank) d1B/1R1 (leave empty) Defines Pair Span: Shading covers indices of 1B and 1R1. Name is rendered in the top header box.
Pair Definition Syntax Rules
  • A pair definition row is detected when path is empty and data_key or test_code contains a forward slash / or starts with d/D.
  • Format: d<InitialCode>/<FinalCode> (e.g. d1B/1R1, d1B/1R2, 1B/1R1).
  • The codes (e.g. 1B and 1R1) must match the data_key or test_code of rows where path is populated.
  • The Name column of the pair row provides the text rendered inside the top header box over the shaded span. If left blank, it defaults to the raw key (e.g. d1B/1R1).

4. PlotSelection.csv & Custom Unit Conversions

Batch Plotting Control

Batch plotting functions (Steps 4, 6, and 8) utilize PlotSelection.csv located in the root project folder. If this file does not exist, running any batch step automatically generates it with all discovered variables and sets Plotted = 0.

File Structure

Column Header Type Description Example
Variable String Exact internal metric name from UnFormattedDataL2.csv. Thermal efficiency - with char
Plotted Integer (0 or 1) Set to 1 to include in batch plotting; set to 0 to skip. 1
Name String (Optional) Custom display name used for the Y-axis title. If left blank, defaults to the raw variable name. Thermal Efficiency (Char Incl.)
Units String (Optional) Target units. If different from source units, automatic conversion is performed! % or mg/MJ

Supported Automatic Unit Conversions

LEMS includes built-in unit conversion factors during plotting:

  • g/MJ ↔ mg/MJ (factor of 1,000)
  • g/min ↔ mg/min (factor of 1,000)
  • g/kg ↔ mg/kg (factor of 1,000)
  • fraction ↔ % (factor of 100)
  • g ↔ mg (factor of 1,000)

Step 3 create custom boxplot

Renders an individual boxplot for a single user-chosen variable showing medians, quartiles, whiskers, and individual scatter data points (with mean markers as black 'x' symbols).

Prerequisites & Inputs

  • Required Data: Each test's UnFormattedDataL2.csv.
  • Pairs Mode: Activated when PairsUnformattedDataL2FilePaths.csv is in the root directory.
  • Interaction: An EasyGUI dialog opens prompting: "Select a variable to compare". Choose any metric from the list.

Outputs Generated

  • Paired Mode: L3PairsBoxPlot_[variable].png (includes pair shading, divider lines, and top header boxes).
  • Standard Mode: L3BoxPlot_[variable].png (standard unshaded comparison).

Step 4 create multiple boxplots at once

Batch processes and renders boxplots for every variable flagged with Plotted = 1 in PlotSelection.csv, applying custom Y-axis display names and unit conversions.

Outputs Generated

  • Paired Mode: L3PairsBoxPlot_[variable].png for each selected metric.
  • Standard Mode: L3BoxPlot_[variable].png for each selected metric.

Step 5 create custom bar chart

Generates a bar chart with 95% confidence interval error caps for a single user-selected variable.

Outputs Generated

  • Paired Mode: L3PairsBarChart_[variable].png (paired alternating shading with flush 0-based coordinate alignment).
  • Standard Mode: L3BarChart_[variable].png.

Step 6 create multiple barcharts at once

Batch generates bar charts with error caps for all variables enabled in PlotSelection.csv.

Outputs Generated

  • Paired Mode: L3PairsBarChart_[variable].png for each enabled variable.
  • Standard Mode: L3BarChart_[variable].png.

Step 7 create custom scatter plot

Interactive Cursor Hover

Generates an interactive scatter plot showing all test replicate points (blue dots) alongside group mean horizontal bars (red markers) for a chosen variable.

Feature: Interactive Mouse-Over Tooltips

In this branch, matplotlib mouse-motion events (motion_notify_event) are attached to the interactive figure:

  • Hovering your mouse over any blue scatter point reveals a tooltip with the specific replicate test name and exact numeric value with units.
  • Hovering over any red average marker displays the group average value and unit string.
  • Tooltips automatically track the cursor and hide when moving outside the marker radius.

Outputs Generated

  • Paired Mode: L3PairsScatterPlot_[variable].png (includes pair shading + top header titles).
  • Standard Mode: L3ScatterPlot_[variable].png.

Step 8 create multiple scatter plots at once

Batch Hover Plots

Batch generates scatter plots with interactive hover capabilities and pair shading for every variable marked with Plotted = 1 in PlotSelection.csv.

Outputs Generated

  • Paired Mode: L3PairsScatterPlot_[variable].png for each metric.
  • Standard Mode: L3ScatterPlot_[variable].png for each metric.

Step 9 create subplots of scatter plots

Renders a multi-panel subplot figure grouping scatter metrics defined in SubplotSelection.csv. Forwards test labels and pair group metadata.

Outputs Generated

  • L3SubplotScatterPlot.png saved directly in the project root directory.
