LEMSDataCruncher_L3 Documentation

Data Processing Pipeline — Detailed Workflow & File Specifications for Steps 1 through 3

Session Initialization & Folder Selection

When running LEMSDataCruncher_L3.py, you will first choose between:

  • CLI Mode (cli): You are prompted for a root folder_path. The folder must contain UnformattedDataL2FilePaths_DataEntrySheetFilePaths.csv, which links to each group’s DataEntrySheetFilePaths.csv and lists the test paths.
  • GUI Mode (default): You enter the number of test runs and select each test’s Data Entry Form via file picker dialog ([testname]_TE_DataEntryForm.xlsx). The target folder is determined from the directory where the selected file lives.
  • Execution Mode: Choose 1 for Interactive Mode (plots open in Matplotlib, popups prompt for inputs) or 2 for Reprocessing Mode (runs in parallel across worker processes, non-interactive, reads existing parameters).

Step 1 plot raw data

Plots all raw time-series sensor channels against time. Verifies signal continuity, timestamps, and data validity before running calculations.

Target Folder File Prerequisites

Status File Name Pattern Description & Purpose
Required [testname]_RawData.csv Main raw sensor box CSV export containing timestamps, calibration headers, and time-series sensor readings (CO, CO2, PM, temperatures, etc.).
Optional [testname]_FormattedCombinedScaleData.csv If combined fuel scale data was previously generated in Step 3, it is automatically read and included in the time-series plot.
Auto-Created [testname]_rawplots.csv Plot configuration file. If missing, it will be automatically generated with default values.

User Decisions & Inputs Required

1. Channel Selection & Scaling in [testname]_rawplots.csv

When Step 1 runs for the first time, it discovers all plottable channels and writes [testname]_rawplots.csv with Plotted = 0 (disabled). To view specific channels:

  • Open [testname]_rawplots.csv in a text editor or spreadsheet program.
  • Set Plotted to 1 for any channel you want to display (e.g., CO, CO2, PM).
  • Adjust Scale multipliers as needed (e.g., 0.1 or 10) so channels with different magnitudes fit on one graph.
  • (Optional) Assign colors or numeric plot Order (higher values plot on top). Save the file and re-run Step 1.
2. Window Interaction (Interactive Mode 1)

An interactive Matplotlib window opens displaying the graph. The user inspects the raw data curves, zooms/pans as needed, and closes the window to finish the step and return to the main menu.

In Reprocessing Mode (2): Matplotlib runs headless (Agg backend). No user input is required; the image is generated directly.

Output Files Generated

Status Output File Description
Generated [testname]_rawplots.csv Table specifying plottable variables, active flags (Plotted), scale factors, colors, and order.
Generated [testname]_rawplot.png High-resolution image rendering of the raw sensor time-series plot.
Updated [testname]_log.txt & L3_log.txt Log files updated with execution status, timestamps, and error messages (if any).

Step 2 load data entry form

Parses the test metadata, fuel parameters, moisture contents, and thermal mass data from the test data entry sheet and flattens them into a structured key-value CSV file used by all subsequent calculation steps.

Target Folder File Prerequisites

Status File Name Pattern Description & Purpose
Required [testname]_TE_DataEntryForm.xlsx (or .csv) The completed test spreadsheet containing named input cells/columns for stove configuration, fuel specifications, tare weights, start/end times, and test phases.

User Decisions & Inputs Required

Pre-Run Data Integrity Check

Step 2 requires no interactive terminal prompts or popup dialogs while executing. However, the user must ensure that the Excel Data Entry Form is completely filled out prior to execution:

  • All required named input cells must contain valid numbers (e.g., initial/final pot water weights, fuel moisture percentage, wood mass, tare weights).
  • Phase time markers and background durations must be properly entered.
  • The file must not be locked or open in Microsoft Excel with unsaved changes.

Output Files Generated

Status Output File Description
Generated [testname]_EnergyInputs.csv Standardized 4-column CSV (variable, units, value, uncertainty) containing all parsed inputs from the spreadsheet for use in energy and emission calculations.
Updated [testname]_log.txt & L3_log.txt Appends loading confirmation and output path.
Tip: If you change any weights, fuel parameters, or times in the Excel spreadsheet later, you must re-run Step 2 so [testname]_EnergyInputs.csv reflects the new values before running downstream calculation steps.

Step 3 load additional raw data files (heating stoves only)

Processes auxiliary instrumentation files commonly used during heating stove tests (continuous fuel scales, TSI NanoScan, TEOM, Sensirion air flow meters, TSI OPS, and Pico loggers) into unified, formatted CSVs.

Target Folder File Prerequisites

Note: None of these individual files are strictly mandatory. The script checks each instrument independently; if a file is not found, it is safely skipped without halting the program.

Status File Name Pattern Instrument / Source
Optional [testname]_ScaleRawData.csv Standard continuous fuel scale raw log.
Optional [testname]_IntScaleRawData.csv Intelligent Scale raw log.
Optional [testname]_AdamScaleRawData.csv Adam Equipment precision balance raw log.
Optional [testname]_NanoscanRawData.csv TSI NanoScan SMPS nanoparticle sizer export.
Optional [testname]_TEOMRawData.txt Thermo Scientific TEOM continuous particulate monitor text export.
Optional [testname]_SenserionRawData.csv Sensirion flow meter & environmental sensor log.
Optional [testname]_OPSRawData.csv TSI Optical Particle Sizer (OPS) raw export.
Optional [testname]_PicoRawData.csv PicoTech data logger export (also references [testname]_RawData.csv for clock synchronization).

User Decisions & Inputs Required

Sensirion Fan & Flow Configuration (Interactive Mode 1)

If [testname]_SenserionRawData.csv exists and [testname]_SenserionInputs.csv has not yet been created, popup dialogs (easygui.multenterbox) prompt the user for the following decisions:

  • Fan Flow Assignment: For each detected flow channel, specify whether it is Primary or Secondary (used to calculate total airflow).
  • Orifice / Duct Geometry: For each flow channel, enter the duct/hole diameter in cm ([name]_dia) and the number of holes ([name]_num) to calculate air velocity.
  • Thermocouple Channels: Enter descriptive names for each thermocouple sensor (TC channels).
  • Differential Pressure Channels: Enter descriptions/assignments for each deltaP channel.

In Reprocessing Mode (2): The script expects [testname]_SenserionInputs.csv to already exist from a previous run and loads it automatically without dialog prompts.

Automatic Scale Merging

If both [testname]_FormattedScaleData.csv and [testname]_FormattedAdamScaleData.csv are generated, the script automatically synchronizes their timestamps and merges them into a combined scale output. No user decision is required.
