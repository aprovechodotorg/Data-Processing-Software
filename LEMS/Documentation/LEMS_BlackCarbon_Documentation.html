LEMS Black Carbon Documentation

Data Entry Workflow — Required Files, Overrides, Outputs & Reprocess Mode

1. Starting Files Required

Before running Black Carbon data entry for a test, the following files should be present in the test folder:

Status File Name Purpose
Required <testname>_<filterID>.jpeg Photograph of the BC filter on the radial card (also supports .jpg or .png). <filterID> must match the BC filter number.
Fallback <testname>_GravInputs.csv Supplies active phases and default gravimetric filter numbers (used only if no BC inputs exist yet).
Fallback <testname>_GravOutputs.csv Supplies default phase exposure times and gravimetric digital flow rates (used only if no BC inputs exist yet).

2. General Idea & Why Overrides are Needed

In some LEMS test setups, the system operates with digital gravimetric sampling lines plus a third sampling line without digital flow monitoring (for example, a constant 3 LPM line).

Core Capabilities:
  • Different Filter Number: You can specify a black carbon filter ID that is completely different from the gravimetric filter ID in GravInputs.csv.
  • Override Digital Flow Rate: You can specify a sample flow rate that overrides the digital flow rate recorded in GravOutputs.csv.
  • Normally Occurs Only Once: This override normally only occurs once during initial data entry. The values are saved to BCInputs.csv and reused automatically without prompting again.

3. How the User Overrides & Modifies Values

When you run Black Carbon data entry in interactive mode (via the GUI button or inputmethod = '1'), a Filter Inputs popup dialog appears:

  • Override Filter Number (filterID_<phase>):
    Defaults to the gravimetric filter number (e.g. 1). Change this to your dedicated Black Carbon filter ID (e.g. 201). The software searches for <testname>_201.jpeg.
  • Override Flow Rate (Qsample_<phase>):
    Defaults to the gravimetric digital flow rate from GravOutputs.csv. If the BC line ran on a third line without flow monitoring (e.g. 3.0 LPM), enter 3.0 directly.
  • Phase Time & Filter Radius:
    Verify phase_time_<phase> (minutes) and deposit radius filterRadius_<filter> (defaults to 1.95 mm).
Can the data be changed again after being entered?

Yes, through either method:

  • Through the Popup: If you click the "Black Carbon" button in interactive mode again, the popup re-opens with your previously entered BC values pre-filled. You can edit any field, click OK, and the changes are immediately saved to BCInputs.csv.
  • By Editing the CSV File: You can open <testname>_BCInputs.csv in Excel or a text editor and update any value directly. During non-interactive runs or reprocess mode, these values are read straight from the file.

4. Files Created

Status File Created Description
Saved Inputs <testname>_BCInputs.csv Contains the authoritative BC parameters (custom filter IDs, custom flow rates, phase times, radii).
Results <testname>_BCOutputs.csv Final optical & emissions calculations: BCloading (μg/cm²), BCconcentration (cm³/μg), BCmass (μg), and BCemissionrate (μg/min).
Debug Image <testname>_<filterID>_Debug.jpg Image showing QR code alignment and the detected circular filter sampling area for visual verification.
Log <testname>_log.txt Execution log with timestamps and status messages.

5. Reprocess Mode (Non-Interactive Execution)

When running in non-interactive batch mode (inputmethod = '2') or reprocessing an already-entered test:

  • No popup prompt: The user is not asked to enter filter numbers or flow rates again.
  • Files Used:
    • <testname>_BCInputs.csv: Read as the authoritative input file. Preserves all previously entered filter numbers and flow rate overrides.
    • <testname>_<filterID>.jpeg: Filter image matching the stored BC filter ID.
  • Files Overwritten/Updated:
    • <testname>_BCOutputs.csv and <testname>_<filterID>_Debug.jpg are recomputed and updated directly.
